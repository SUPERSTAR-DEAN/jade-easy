# 外部库

这个目录存放本项目使用的外部库。

- [json-20250517.jar](json-20250517.jar)：一个在 Java 中处理 JSON 数据的库。更多信息见 [JSON-java GitHub 仓库](https://github.com/stleary/JSON-java)
- [opencsv-3.9.jar](opencsv-3.9.jar)：一个在 Java 中读写 CSV 文件的库。更多信息见 [OpenCSV SourceForge 页面](http://opencsv.sourceforge.net)。
- [JadeUPHF.jar](JadeUPHF.jar)：一个用于集成 JADE-UPHF 智能体平台的库。更多信息见 [JadeUPHF GitHub 仓库](https://emmanueladam.github.io/JadeUPHF/)
